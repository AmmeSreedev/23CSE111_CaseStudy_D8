## 3. Problem Description :

In many colleges, student complaints are handled informally through emails or physical registers. This results in lost 
complaints, delayed responses, and a lack of accountability. Students feel unheard while administrators lack 
structured tracking. ResolveIt addresses this by providing a transparent digital platform where complaints are logged, 
tracked, and resolved systematically through defined roles — Student, Admin, and Manager.

## 4.How to Run the code:

Make a Project in Eclipse and then run the ResolveItWebApplication.java as Java Application.

## 5.Sample Input/Output:

The Input is given as Student compliant on the Website and Output is given as the resolving process managed by the admin and manager.

## 6.Tools Used:

Java for the Backend , CSS/HTML for the User Interface Design and SpringBoard to create the Web application.
